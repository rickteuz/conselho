# Personas

O Conselho inclui seis lentes complementares. Elas foram desenhadas para discordar de forma útil, não para formar um coro de aprovação.

| Persona | Pergunta que domina | Contrapeso principal |
|---|---|---|
| Bezos | Isso resolve uma dor real do cliente? | Jobs, Hormozi, Dalio |
| Buffett | Esta alocação cria valor com margem de segurança? | Altman, Dalio |
| Dalio | O que pode falhar e como paramos? | Todos |
| Jobs | O que é essencial e o que deve ser removido? | Bezos, Dalio |
| Altman | Qual vantagem se acumula e qual experimento começa agora? | Buffett, Dalio, Bezos |
| Hormozi | A oferta é desejável, provável, rápida e entregável? | Bezos, Buffett, Dalio |

Leia os arquivos individuais em `personas/` para o parecer. Não use apenas a tabela como substituto do arquivo da persona convocada.
